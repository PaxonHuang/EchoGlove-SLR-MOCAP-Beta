  analysis:

  接线审查结果

  可行的部分

  你的核心接线方案是正确的:
  - GPIO8/9 → TCA9548A SDA/SCL — 符合 SOP
  - BNO085 在 TCA9548A Ch5 — 符合 SOP
  - BNO085 INT → GPIO21 — 符合 SOP
  - 主总线加 I2C 上拉 — 正确

  需要注意的差异

  1. 上拉电阻值不同

  ┌────────────────┬──────────────┬──────────┬────────────┐
  │      位置      │   SOP 文档   │ 你的接线 │    评估    │
  ├────────────────┼──────────────┼──────────┼────────────┤
  │ 主总线         │ 2.2kΩ        │ 5.1kΩ    │ 可行但偏弱 │
  ├────────────────┼──────────────┼──────────┼────────────┤
  │ 子通道 (Ch0-5) │ 4.7kΩ × 12个 │ 缺失     │ 问题       │
  └────────────────┴──────────────┴──────────┴────────────┘

  5.1kΩ 上拉在 400kHz I2C 下可以工作，但上升时间会稍慢。TI TCA9548A 数据手册建议
   I2C Fast Mode (400kHz) 的上拉在 1kΩ-4.7kΩ 范围。5.1kΩ
  略超上限，但主总线只有一个设备 (TCA9548A)，总线电容低，实际应该没问题。

  2. 子通道上拉电阻缺失 — 这是关键问题

  SOP 文档要求每个 TCA9548A 子通道 (SDx/SCx) 都有 4.7kΩ 上拉到
  3.3V。你目前只连了 Ch5 (BNO085)，没有加 Ch5 的上拉。

  BNO085 的影响: BNO085 breakout 板通常自带 I2C 上拉电阻 (Adafruit 的 BNO085
  breakout 有内置 10kΩ 上拉)，所以即使你没加外部上拉，BNO085
  通道可能也能工作。但需要确认你的 BNO085 breakout 是否有内置上拉。

  TMAG5273 的影响: TMAG5273 未到货，所以 Ch0-4 上拉暂时不需要。等 TMAG5273
  到货后，每个通道必须加 4.7kΩ 上拉。

  3. 你的接线描述有一个笔误

  你说 PCA9548A1 SC0 ── BNO085 SCL，但根据你的拓扑描述应该是 PCA9548A1 SC5 ── 
  BNO085 SCL。请确认是 SC5 还是 SC0 连到 BNO085 SCL。SOP 指定 BNO085 在 Ch5
  (SD5/SC5)。

  建议方案

  现在可以做的 (不需要改动):
  1. 用 5.1kΩ 主总线上拉先测试，如果 I2C 通信不稳定再换 2.2kΩ
  2. 先只验证 TCA9548A (地址 0x70) 和 BNO085 (Ch5)
  3. TMAG5273 到货后再加子通道上拉

  固件需要适配:
  - TMAG5273 未到货，固件中 Hall sensor 初始化失败是预期行为
  - 需要确保 SensorManager.begin() 在 Hall 初始化失败时不卡住
  (当前代码已处理：hall_ok < 5 只是 WARNING)
  - 传感器数据中 Hall 部分会是 0 (Kalman 滤波器初始估计值)
  - CSV 输出中 Hall 数据会是 0，IMU 数据应该是真实的

  我建议的下一步: 先烧录固件验证 TCA9548A + BNO085 是否正常工作，然后再讨论
  Phase 3 推理方案。是否同意这个顺序？

## 1 V5 接线概览

### 1.1 V5 与 V3 关键区别

| 项目 | V3 | V5 |
|------|----|----|
| I²C 拓扑 | TCA9548A MUX + 6 子通道 | 扁平总线（无 MUX） |
| 手指传感器 | TMAG5273 × 15 (I²C 0x22) | SpectraFlex × 5 (ADC) |
| ADC 芯片 | 无 | ADS1115 × 2 (0x48/0x49) |
| 上拉电阻 | 2kΩ 主 + 4.7kΩ 子通道 | **4.7kΩ** 主总线 |
| 通信 | WiFi + BLE | ESP-NOW |

### 1.2 V5 I²C 总线拓扑

```
ESP32-S3 GPIO8(SDA) GPIO9(SCL)
    │           │
    ├── 4.7kΩ ──┤── 3.3V (上拉)
    │           │
    ├───────────┼───────────┬───────────┐
    │           │           │           │
┌───┴───┐  ┌───┴───┐  ┌───┴───┐       │
│ADS1115│  │ADS1115│  │BNO085 │       │
│ #1    │  │ #2    │  │       │       │
│ 0x48  │  │ 0x49  │  │ 0x4B  │       │
└───────┘  └───────┘  └───────┘       │
```

### 1.3 电阻值速查

| 电阻值 | 颜色码 | 用途 | 数量 |
|--------|--------|------|------|
| 4.7kΩ | 黄紫红金 | I²C 上拉 (SDA/SCL → 3.3V) | 2 |
| 47kΩ | 黄紫橙金 | 柔性传感器分压 (→ 3.3V) | 5 |

> **⚠️ 不要混淆**：4.7kΩ（4千7百欧）和 47kΩ（4万7千欧）相差 10 倍！

## 2 I²C 总线检测

### 2.1 上拉电阻检测（断电状态）

**万用表设置**: 电阻档 (Ω)

| 测试点 | 预期值 | 容差 | 说明 |
|--------|--------|------|------|
| GPIO8 (SDA) ↔ 3.3V | **4.7kΩ** | ±5% | SDA 上拉 |
| GPIO9 (SCL) ↔ 3.3V | **4.7kΩ** | ±5% | SCL 上拉 |
| SDA ↔ SCL | >100kΩ | — | 不应短路 |
| SDA ↔ GND | >100kΩ | — | 不应短路 |

### 2.2 总线电压检测（上电状态）

**万用表设置**: 直流电压档 (V DC)

| 测试点 | 预期值 | 说明 |
|--------|--------|------|
| SDA ↔ GND | 3.3V | 空闲时高电平 |
| SCL ↔ GND | 3.3V | 空闲时高电平 |

> **如果 SDA/SCL 电压为 0V**：上拉电阻缺失或 SDA/SCL 被设备拉低（总线锁死）。

### 2.3 I²C 设备扫描（固件验证）

```bash
pio device monitor -b 115200
```

**预期输出**:
```
I2C scan: found 0x48 (ADS1115 #1)
I2C scan: found 0x49 (ADS1115 #2)
I2C scan: found 0x4B (BNO085)
I2C scan: 3 devices found
```

### 2.4 I²C 上拉电阻计算依据

- I²C 标准模式 (100kHz)：上升时间 t_r ≤ 1000ns
- 公式：R_pull ≤ t_r / (0.8473 × C_bus)
- 总线电容估算：3 个 IC (约 60pF) + 面包板跳线 (约 80pF) ≈ 140pF
- R_pull ≤ 1000ns / (0.8473 × 140pF) ≈ 8.4kΩ
- **4.7kΩ** 提供充足裕量，同时不会过强（空闲电流仅 0.7mA/线）

## 3 ADS1115 ADC 检测

### 3.1 地址验证

| 设备 | ADDR 引脚 | 预期地址 |
|------|-----------|----------|
| ADS1115 #1 | GND | 0x48 |
| ADS1115 #2 | 3.3V | 0x49 |

**万用表检测** (断电):
- ADS1115 #1 ADDR ↔ GND: 应短路 (0Ω)
- ADS1115 #2 ADDR ↔ 3.3V: 应短路 (0Ω)

### 3.2 ADC 输入检测

**万用表设置**: 直流电压档 (V DC)

| 测试点 | 预期范围 | 说明 |
|--------|----------|------|
| AIN0 ↔ GND | 1.0V ~ 2.3V | Flex 0-2 或 Flex 3-4 |
| AIN1 ↔ GND | 1.0V ~ 2.3V | 取决于传感器弯曲程度 |
| AIN2 ↔ GND | 1.0V ~ 2.3V | 伸直=低电压，弯曲=高电压 |

### 3.3 ADS1115 I²C 通信检测

如果 I²C 扫描能找到 ADS1115 但读取失败（err=5 或 err=263），检查：

| 检查项 | 方法 | 预期 |
|--------|------|------|
| VCC 电压 | 万用表：VCC↔GND | 3.3V ±0.1V |
| GND 连通 | 万用表：GND↔ESP32 GND | 0Ω |
| SDA 连通 | 万用表：ADS1115 SDA↔GPIO8 | 0Ω |
| SCL 连通 | 万用表：ADS1115 SCL↔GPIO9 | 0Ω |
| 去耦电容 | 目视检查 VCC 旁 | 100nF 陶瓷电容 |

## 4 BNO085 IMU 检测

### 4.1 地址验证

| 测试点 | 预期 | 说明 |
|--------|------|------|
| BNO085 SDA ↔ GPIO8 | 通路 | 直连 |
| BNO085 SCL ↔ GPIO9 | 通路 | 直连 |
| I²C 地址 | 0x4B | 固件扫描确认 |

### 4.2 RST 引脚检测（关键！）

**万用表设置**: 通断档或电阻档

| 测试点 | 预期 | 说明 |
|--------|------|------|
| RST ↔ 3.3V | 通路 (0Ω) | **必须拉高** |
| RST ↔ GND | 断路 (>100kΩ) | 不能拉低 |

> **⚠️ RST 悬空 = BNO085 不工作**。RST 引脚必须接到 3.3V。

### 4.3 PS0/PS1 引脚检测

| 测试点 | 预期 | 说明 |
|--------|------|------|
| PS0 ↔ 3.3V | 通路 | 选择 I2C 模式 |
| PS1 ↔ GND | 通路 | 选择 I2C 模式 |

### 4.4 数据验证

**万用表设置**: 直流电压档 (V DC)

| 测试点 | 预期 | 说明 |
|--------|------|------|
| INT ↔ GND | 脉冲 | 数据就绪时触发 |

**固件验证**: Euler/Gyro 数据应非零且随运动变化。

## 5 柔性传感器检测

### 5.1 分压电路检测

**万用表设置**: 电阻档 (Ω)

| 测试点 | 预期 | 说明 |
|--------|------|------|
| Flex 传感器两端 | 22kΩ ~ 110kΩ | 伸直~弯曲 |
| 47kΩ 电阻两端 | 47kΩ ±5% | 固定上拉电阻 |

### 5.2 电压检测

**万用表设置**: 直流电压档 (V DC)

| 状态 | ADS1115 AIN 电压 | 说明 |
|------|------------------|------|
| 伸直 | ~1.05V | 传感器电阻低 |
| 半弯曲 | ~1.86V | 中间状态 |
| 完全弯曲 | ~2.31V | 传感器电阻高 |

### 5.3 分压电路接法

```
3.3V ── [47kΩ] ──┬── [Flex Sensor] ── GND
                  │
                  └── ADS1115 AINx
```

> **⚠️ 重要：47kΩ 接 3.3V 侧，传感器接 GND 侧**
>
> 这样连接时：
> - **伸直**：传感器电阻低 (~22kΩ) → AIN 电压低 (~1.05V)
> - **弯曲**：传感器电阻高 (~110kΩ) → AIN 电压高 (~2.31V)

**电压计算**：
```
V_AIN = 3.3V × R_flex / (R_flex + 47kΩ)

伸直 (R_flex=22kΩ):  V = 3.3 × 22k/69k  = 1.05V
半弯 (R_flex=60kΩ):  V = 3.3 × 60k/107k = 1.86V
全弯 (R_flex=110kΩ): V = 3.3 × 110k/157k = 2.31V
```

## 8 常见故障速查表

### 8.1 I²C 相关

| 现象 | 万用表检测 | 可能原因 | 解决方法 |
|------|-----------|----------|----------|
| 扫描无设备 | SDA/SCL 电压=0V | 上拉电阻未接 | 安装 4.7kΩ 上拉 |
| 扫描无设备 | SDA/SCL 电压正常 | SDA/SCL 接反 | 交换 GPIO8/9 |
| 扫描无设备 | 电压正常，接线正确 | BNO085 RST 悬空 | RST 接 3.3V |
| 仅 0x4B | — | ADS1115 未接 | 检查 ADS1115 接线 |
| 地址冲突 | — | 两个 ADS1115 ADDR 相同 | #1→GND, #2→3.3V |
| 扫描卡死 | SDA 电压=0V | I²C 总线锁死 | 断电重启 |
| 读取 err=5 | — | 设备不发 ACK | 检查 VCC/GND |
| 读取 err=263 | — | I²C 超时 | 检查 SDA/SCL 连接 |

### 8.2 柔性传感器相关

| 现象 | 万用表检测 | 可能原因 | 解决方法 |
|------|-----------|----------|----------|
| ADC 始终 0 | AIN=0V | 分压电阻未接 | 安装 47kΩ 上拉到 3.3V |
| ADC 始终满 | AIN=3.3V | 传感器断路 | 检查焊接 |
| 噪声大 | 电压波动>0.1V | 走线过长 | 缩短引线 |
| 弯曲时电压降低 | — | 传感器/电阻位置接反 | 47kΩ 接 3.3V，传感器接 GND |

### 8.3 ESP-NOW 相关

| 现象 | 检测方法 | 可能原因 | 解决方法 |
|------|----------|----------|----------|
| 无数据 | 接收器无打印 | MAC 地址未配对 | 检查 peer 配置 |
| 丢包 | 统计丢包率>5% | 距离/干扰 | 缩短距离，远离干扰 |
| 数据错乱 | 检查 packet 结构 | 版本不匹配 | 固件版本一致 |

## 9 I²C 总线故障深度排查

### 9.1 I²C 扫描卡死

**现象**：固件执行 I²C 扫描时卡住，无输出。

**原因**：I²C 总线被设备锁死（SDA 被拉低）。

**排查步骤**：
1. 断电
2. 万用表电阻档：SDA↔GND，应 >100kΩ
3. 如果 SDA↔GND = 0Ω：某个设备 SDA 引脚短路
4. 逐个断开设备，找到问题设备
5. 检查面包板跳线是否接触不良

### 9.2 I²C 扫描成功但读取失败

**现象**：扫描能找到设备（0x48, 0x49, 0x4B），但实际读取返回 err=5 或 err=263。

**原因**：
- 设备 ACK 地址字节，但数据传输阶段失败
- 可能是时序问题或总线电容过大

**排查步骤**：
1. 降低 I²C 频率到 50kHz 测试
2. 检查去耦电容（每个 VDD 旁 100nF）
3. 缩短跳线长度
4. 检查是否有多个上拉电阻并联（值太小）

### 9.3 面包板常见问题

| 问题 | 现象 | 解决方法 |
|------|------|----------|
| 跳线接触不良 | 时好时坏 | 重新插拔，换跳线 |
| 面包板内部断路 | 某行不通 | 换一行插 |
| 电源轨短路 | 3.3V↔GND 短路 | 检查面包板电源轨 |
| 跳线过长 | 信号衰减 | 使用短线 |

### 9.4 系统性排查流程

```
1. 断电状态
   ├── 检查 SDA↔3.3V 电阻 = 4.7kΩ
   ├── 检查 SCL↔3.3V 电阻 = 4.7kΩ
   ├── 检查 SDA↔SCL > 100kΩ
   ├── 检查 SDA↔GND > 100kΩ
   ├── 检查 BNO085 RST↔3.3V = 通路
   ├── 检查 ADS1115 #1 ADDR↔GND = 通路
   └── 检查 ADS1115 #2 ADDR↔3.3V = 通路

2. 上电状态
   ├── 检查 SDA 电压 = 3.3V
   ├── 检查 SCL 电压 = 3.3V
   ├── 检查所有 VCC = 3.3V
   └── 检查所有 GND = 0V

3. 固件测试
   ├── I²C 扫描：应找到 3 个设备
   ├── ADS1115 读取：应返回 ADC 值
   └── BNO085 读取：应返回 IMU 数据
```

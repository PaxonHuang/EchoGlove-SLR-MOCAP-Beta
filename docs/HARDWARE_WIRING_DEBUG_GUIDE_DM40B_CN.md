## 1 V5 接线概览

### 1.1 V5 与 V3 关键区别

| 项目 | V3 | V5 |
|------|----|----|
| I²C 拓扑 | TCA9548A MUX + 6 子通道 | 扁平总线（无 MUX） |
| 手指传感器 | TMAG5273 × 15 (I²C 0x22) | SpectraFlex × 5 (ADC) |
| ADC 芯片 | 无 | ADS1115 × 2 (0x48/0x49) |
| 上拉电阻 | 2kΩ 主 + 4.7kΩ 子通道 | 2.2kΩ 主总线 |
| 通信 | WiFi + BLE | ESP-NOW |

### 1.2 V5 I²C 总线拓扑

```
ESP32-S3 GPIO8(SDA) GPIO9(SCL)
    │           │
    ├── 2.2kΩ ──┤── 3.3V (上拉)
    │           │
    ├───────────┼───────────┬───────────┐
    │           │           │           │
┌───┴───┐  ┌───┴───┐  ┌───┴───┐       │
│ADS1115│  │ADS1115│  │BNO085 │       │
│ #1    │  │ #2    │  │       │       │
│ 0x48  │  │ 0x49  │  │ 0x4B  │       │
└───────┘  └───────┘  └───────┘       │
```

## 2 I²C 总线检测

### 2.1 上拉电阻检测（断电状态）

**万用表设置**: 电阻档 (Ω)

| 测试点 | 预期值 | 容差 | 说明 |
|--------|--------|------|------|
| GPIO8 (SDA) ↔ 3.3V | 2.2kΩ | ±5% | SDA 上拉 |
| GPIO9 (SCL) ↔ 3.3V | 2.2kΩ | ±5% | SCL 上拉 |
| SDA ↔ SCL | >100kΩ | — | 不应短路 |
| SDA ↔ GND | >100kΩ | — | 不应短路 |

### 2.2 总线电压检测（上电状态）

**万用表设置**: 直流电压档 (V DC)

| 测试点 | 预期值 | 说明 |
|--------|--------|------|
| SDA ↔ GND | 3.3V | 空闲时高电平 |
| SCL ↔ GND | 3.3V | 空闲时高电平 |

### 2.3 I²C 设备扫描（固件验证）

```bash
pio device monitor -b 115200
```

**预期输出**:
```
I2C scan: found 0x48 (ADS1115 #1)
I2C scan: found 0x49 (ADS1115 #2)
I2C scan: found 0x4B (BNO085)
I2C scan: 3 devices found
```

## 3 ADS1115 ADC 检测

### 3.1 地址验证

| 设备 | ADDR 引脚 | 预期地址 |
|------|-----------|----------|
| ADS1115 #1 | GND | 0x48 |
| ADS1115 #2 | 3.3V | 0x49 |

**万用表检测** (断电):
- ADS1115 #1 ADDR ↔ GND: 应短路 (0Ω)
- ADS1115 #2 ADDR ↔ 3.3V: 应短路 (0Ω)

### 3.2 ADC 输入检测

**万用表设置**: 直流电压档 (V DC)

| 测试点 | 预期范围 | 说明 |
|--------|----------|------|
| AIN0 ↔ GND | 0.3V ~ 2.8V | Flex 0-2 或 Flex 3-4 |
| AIN1 ↔ GND | 0.3V ~ 2.8V | 取决于传感器弯曲程度 |
| AIN2 ↔ GND | 0.3V ~ 2.8V | 伸直=低电压，弯曲=高电压 |

## 4 BNO085 IMU 检测

### 4.1 地址验证

| 测试点 | 预期 | 说明 |
|--------|------|------|
| BNO085 SDA ↔ GPIO8 | 通路 | 直连 |
| BNO085 SCL ↔ GPIO9 | 通路 | 直连 |
| I²C 地址 | 0x4B | 固件扫描确认 |

### 4.2 数据验证

**万用表设置**: 直流电压档 (V DC)

| 测试点 | 预期 | 说明 |
|--------|------|------|
| INT ↔ GND | 脉冲 | 数据就绪时触发 |

**固件验证**: Euler/Gyro 数据应非零且随运动变化。

## 5 柔性传感器检测

### 5.1 分压电路检测

**万用表设置**: 电阻档 (Ω)

| 测试点 | 预期 | 说明 |
|--------|------|------|
| Flex 传感器两端 | 10kΩ ~ 100kΩ | 伸直~弯曲 |
| 47kΩ 电阻两端 | 47kΩ ±5% | 固定下拉电阻 |

### 5.2 电压检测

**万用表设置**: 直流电压档 (V DC)

| 状态 | ADS1115 AIN 电压 | 说明 |
|------|------------------|------|
| 伸直 | ~0.3V | 传感器电阻低 |
| 半弯曲 | ~1.5V | 中间状态 |
| 完全弯曲 | ~2.8V | 传感器电阻高 |

## 6 电源系统检测

## 7 ESP-NOW 通信检测

### 7.1 物理层检测

- 确认天线未被遮挡
- 手套与接收器距离 <10m
- 无 2.4GHz 干扰源

### 7.2 协议层检测

**固件验证**:
```
# 手套端
ESP-NOW: sent 69 bytes, status=OK

# 接收器端
ESP-NOW: received 69 bytes from AA:BB:CC:DD:EE:FF
```

## 8 常见故障速查表

### 8.1 I²C 相关

| 现象 | 万用表检测 | 可能原因 | 解决方法 |
|------|-----------|----------|----------|
| 扫描无设备 | SDA/SCL 电压=0V | 上拉电阻未接 | 安装 2.2kΩ 上拉 |
| 扫描无设备 | SDA/SCL 电压正常 | SDA/SCL 接反 | 交换 GPIO8/9 |
| 仅 0x4B | — | ADS1115 未接 | 检查 ADS1115 接线 |
| 地址冲突 | — | 两个 ADS1115 ADDR 相同 | #1→GND, #2→3.3V |

### 8.2 柔性传感器相关

| 现象 | 万用表检测 | 可能原因 | 解决方法 |
|------|-----------|----------|----------|
| ADC 始终 0 | AIN=0V | 分压电阻未接 | 安装 47kΩ 下拉 |
| ADC 始终满 | AIN=3.3V | 传感器断路 | 检查焊接 |
| 噪声大 | 电压波动>0.1V | 走线过长 | 缩短引线 |

### 8.3 ESP-NOW 相关

| 现象 | 检测方法 | 可能原因 | 解决方法 |
|------|----------|----------|----------|
| 无数据 | 接收器无打印 | MAC 地址未配对 | 检查 peer 配置 |
| 丢包 | 统计丢包率>5% | 距离/干扰 | 缩短距离，远离干扰 |
| 数据错乱 | 检查 packet 结构 | 版本不匹配 | 固件版本一致 |

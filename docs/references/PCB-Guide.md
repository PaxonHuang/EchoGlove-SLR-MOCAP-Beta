# EchoGlove V5.0 — PCB 布局指南

> **版本**: V5.0 | **日期**: 2026-06-03
>
> **V3 用户注意**: V5 不使用 TCA9548A MUX 和 TMAG5273。V3 PCB 指南见 `docs/archive/v3/PCB-Guide.md`。

---

## 1 元件布局

### 1.1 手套 PCB 布局

```
                    手背面
    ┌─────────────────────────────────┐
    │  ┌──────┐  ┌──────┐  ┌──────┐ │
    │  │TP4056│  │AMS   │  │WS2812│ │
    │  │充电  │  │1117  │  │LED   │ │
    │  └──────┘  └──────┘  └──────┘ │
    │                                 │
    │  ┌──────────────────────────┐  │
    │  │      ESP32-S3 N16R8      │  │
    │  │      (主控)              │  │
    │  └──────────────────────────┘  │
    │                                 │
    │  ┌──────┐  ┌──────┐           │
    │  │ADS   │  │ADS   │  ┌──────┐ │
    │  │1115  │  │1115  │  │BNO085│ │
    │  │#1    │  │#2    │  │      │ │
    │  │0x48  │  │0x49  │  │0x4B  │ │
    │  └──────┘  └──────┘  └──────┘ │
    └─────────────────────────────────┘
```

### 1.2 关键间距

| 元件 | 最小间距 | 说明 |
|------|----------|------|
| BNO085 ↔ ESP32 | 10mm | 减少 EMI |
| ADS1115 ↔ ESP32 | 5mm | 走线方便 |
| 电池 ↔ BNO085 | 15mm | 远离磁干扰 |

---

## 2 I²C 走线

### 2.1 走线规则

- **SDA/SCL 平行走线**: 长度差 <5mm
- **走线宽度**: ≥0.3mm (12mil)
- **上拉电阻**: 靠近 ESP32-S3 端放置
- **去耦电容**: 每个 IC VCC 脚放 100nF

### 2.2 去耦电容位置

| 元件 | 电容 | 位置 |
|------|------|------|
| ESP32-S3 | 100nF + 10μF | VCC 脚旁 |
| ADS1115 #1 | 100nF | VCC 脚旁 |
| ADS1115 #2 | 100nF | VCC 脚旁 |
| BNO085 | 100nF | VCC 脚旁 |

---

## 3 柔性传感器走线

### 3.1 ADC 输入走线

- 走线长度: <50mm（减少噪声）
- 远离高频信号线（ESP-NOW 天线）
- 分压电阻靠近 ADS1115 ADC 输入端

### 3.2 传感器固定

- 热熔胶固定在手套背面
- 弯曲处预留余量
- 避免锐角弯折

---

## 4 电源走线

### 4.1 电源拓扑

```
LiPo → TP4056 → AMS1117 → 3.3V 平面
                              │
                    ┌─────────┼─────────┐
                    │         │         │
                ESP32-S3  ADS1115  BNO085
```

### 4.2 走线宽度

| 信号 | 最小宽度 | 说明 |
|------|----------|------|
| VBAT | 0.5mm | 电池供电 |
| 3.3V | 0.5mm | 稳压后 |
| GND | 0.5mm | 地平面 |

---

## 5 天线区域

### 5.1 ESP-NOW 天线注意事项

- 天线区域（PCB 边缘）禁止铺铜
- 天线前方 10mm 内无金属
- 天线朝向手掌外侧

---

## 6 焊接注意事项

### 6.1 焊接顺序

1. 电源管理 (TP4056 + AMS1117)
2. ESP32-S3 排针
3. I²C 上拉电阻 (2.2kΩ)
4. ADS1115 模块
5. BNO085 模块
6. 分压电阻 (47kΩ)
7. WS2812B LED
8. 校准按键
9. 柔性传感器引线

### 6.2 焊接温度

| 元件 | 温度 | 说明 |
|------|------|------|
| 排针/电阻 | 320°C | 标准 |
| IC 模块 | 300°C | 低温，避免损坏 |
| 柔性传感器 | 260°C | 低温，快速焊接 |

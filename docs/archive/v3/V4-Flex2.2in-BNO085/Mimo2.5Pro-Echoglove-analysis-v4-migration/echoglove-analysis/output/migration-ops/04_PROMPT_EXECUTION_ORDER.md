## 每个 Prompt 详情

### Prompt 00: 项目上下文

| 属性 | 值 |
|---|---|
| **角色** | 每次必粘贴的前缀 |
| **依赖** | 无 |
| **输出** | 无（只是上下文） |
| **耗时** | 0 |
| **必须配合** | 所有其他 Prompt |

**使用方式：**
```
[粘贴 Prompt 00 内容]
[粘贴当前步骤的 Prompt 内容]
```

---

### Prompt 04: 删除 Hall/MUX 代码

| 属性 | 值 |
|---|---|
| **依赖** | 无 |
| **被依赖** | 01, 06 |
| **输出** | 删除 tmag5273/, tca9548a/ |
| **编译** | 可能暂时编译失败（缺少引用） |
| **耗时** | 10 分钟 |
| **检查点** | `grep -r "tmag5273" glove_firmware/` 无结果 |

**为什么先执行：**
- 删除旧代码不会破坏新代码
- 清理后编译错误更少
- 心理上"迈出第一步"

## 并行执行机会

如果你有多个 Claude Code 实例，以下 Prompt 可以并行：

```
并行组 A: Prompt 01 + Prompt 02 + Prompt 05
并行组 B: Prompt 07 + Prompt 08 + Prompt 12
并行组 C: Prompt 10 + Prompt 11
```

**注意：并行执行时确保每个实例有独立的工作目录或文件不冲突。**

## 失败恢复

如果某个 Prompt 执行失败：

```bash
# 1. 回退最后一步
git reset --hard HEAD~1

# 2. 修复问题（检查错误信息）

# 3. 重新执行该 Prompt

# 4. 如果反复失败，跳过该步，先执行后续步骤
#    （大部分 Prompt 可以独立执行）
```

# Historical Documents Archive

Archived design documents from previous project phases.

## Structure

- `v3/` — V3 EdgeAI Data Glove: Hall sensor architecture (TMAG5273 + TCA9548A MUX), V3 wiring/debug guides, V4 migration drafts
- `v5-ai-drafts/` — V5.0 AI-generated drafts from multiple LLMs (GLM, Kimi, Mimo, Gemini)

## Why archived

V5 migration replaced Hall sensors with flex sensors (Spectra Symbol) and flat I2C bus (no MUX). V5.2 added P4 smart base station. These documents are preserved for historical reference only.

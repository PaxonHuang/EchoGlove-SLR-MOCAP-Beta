|------|-------:|----------:|-----------:|---------:|-----:|

## 6. V5.2 vs V5.1 关键差异说明

### 6.1 UWB测距模块新增

| 项目 | V5.1 | V5.2 | 变化 |
|------|------|------|------|
| 双手距离感知 | 无（依赖IMU估算） | DWM3000 UWB TWR | **新增硬件** |
| 测距精度 | — | ~5cm | **厘米级** |
| 测距范围 | — | 0–50m（开阔环境） | — |
| 增加成本/手套 | — | +¥133.00 | DWM3000(¥130) + SPI排线(¥3) |
| 通信接口 | — | SPI-2（独立总线） | 与I2C传感器无总线冲突 |
| TWR刷新率 | — | 10–20 Hz | 低功耗，对SPI总线占用 < 2% |
| 特征维度增加 | 25维 | **29维** | +1维距离 + 3维相对位姿（IMU推算） |

**设计理由**：双手协作手势（如"拍手"、"交叉握手"、"距离调节"）需要精确的双手间距信息。UWB TWR 测距提供厘米级精度，弥补纯 IMU 方案无法获取双手绝对距离的缺陷。DWM3000 基于 DW3000 芯片（IEEE 802.15.4z），兼容 Apple U1 生态，TWR 精度典型值 5cm。

### 6.2 ESP32-P4基站升级

| 项目 | V5.1 | V5.2 | 变化 |
|------|------|------|------|
| 基站主控 | ESP32-S3 (¥28) | ESP32-P4 (¥500，竞赛提供) | **主控升级** |
| CPU性能 | 240MHz 双核 Xtensa | 400MHz 双核 RISC-V | **+67% 算力** |
| 本地SRAM | 512KB (S3片内) | **512KB** | 持平 |
| PSRAM | 8MB (S3外挂) | **16/32MB** (P4外挂) | **2–4× 扩展** |
| 无线通信 | ESP-NOW (S3内置) | ESP-NOW + Wi-Fi 6 (C6模块) | **Wi-Fi 6 升级** |
| 显示输出 | 无 | **7″ MIPI-DSI 触摸屏** | **新增可视化** |
| 摄像头 | 无 | **MIPI-CSI** | **新增视觉** |
| 音频输出 | 无 | **ES8311 + NS4150 (3W)** | **新增语音播报** |
| 有线连接 | USB-C | USB-C + USB-A ×2 + **RJ45** | **扩展接口** |
| 存储 | 无 | **MicroSD (SDIO 4-bit)** | **新增存储** |
| 基站功能 | ESP-NOW→USB HID 中继 | **中继 + 本地推理 + 显示 + 音频 + 存储** | **质变** |
| 基站成本 | ¥47.20 | ¥520.00 (全价) / ¥20.00 (赞助) | — |

**设计理由**：ESP32-P4-Function-EV-Board 由竞赛方提供，零成本获得高性能基站。P4 的 400MHz 双核 RISC-V + 16/32MB PSRAM 可在基站端部署 L3 全关节 ST-GCN 模型，同时 LVGL 触摸屏提供实时手势可视化与调试界面，ES8311 音频支持语音播报识别结果，极大提升演示效果与用户体验。

### 6.3 特征向量29维扩展

| 特征组 | 维度 | V5.1 | V5.2 | 说明 |
|--------|:----:|:----:|:----:|------|

| IMU 加速度 | 3 | ✓ | ✓ | 三轴加速度 |
| IMU 陀螺仪 | 3 | ✓ | ✓ | 三轴角速度 |
| IMU 磁力计 | 3 | ✓ | ✓ | 三轴磁场强度 |

### 6.4 通信双模冗余

| 项目 | V5.1 | V5.2 |
|------|------|------|
| 手套→基站 | ESP-NOW (2.4GHz) | ESP-NOW (2.4GHz) |
| 备份通道 | 无 | **Wi-Fi TCP/UDP (C6模块)** |
| 有线备份 | 无 | **RJ45 以太网** |
| 抗干扰能力 | 单频段 | **三通道冗余** |
| 切换策略 | — | ESP-NOW优先 → Wi-Fi降级 → 以太网兜底 |

**设计理由**：竞赛现场 2.4GHz 频段可能拥挤，ESP-NOW 丢包率上升时自动切换至 Wi-Fi 或以太网，确保数据链路可靠性。ESP32-C6-MINI-1 同时支持 ESP-NOW 和 Wi-Fi 6，无需额外硬件。

### 单手套 I2C 地址表

| 总线 | 器件 | 地址 | 说明 |
|:----:|------|:----:|------|
| I2C-0 | BNO085 | 0x4B | IMU，专用总线 |

> **地址冲突处理**：BNO085 使用 I2C-0（GPIO 8/9），两颗 ADS1115 共用 I2C-1（GPIO 6/7），地址 0x48/0x49 通过 ADDR 引脚区分，无冲突。

| SPI-2 | DW3000 UWB (DWM3000) | GPIO 13 | MOSI: GPIO 10<br>MISO: GPIO 11<br>SCLK: GPIO 12<br>IRQ: GPIO 14 | 8 MHz | TWR测距，10–20Hz刷新 |

> **SPI与I2C无冲突**：UWB 使用 SPI-2 总线，与 I2C-0/I2C-1 传感器完全独立。
>
> **SPI总线占用分析**：
> - DWM3000 TWR 通信：每次 TWR 交互约 2ms（SPI 8MHz），10Hz 刷新率下 SPI 总线占用率 < 2%
> - ADS1115 通过 I2C-1 采集，与 SPI 无交叉，不存在总线竞争
> - UWB IRQ (GPIO 14) 为中断触发模式，不占用 SPI 带宽

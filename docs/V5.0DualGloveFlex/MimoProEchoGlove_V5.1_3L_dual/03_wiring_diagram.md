│     │  L2: GND   (地平面)          │ ← 完整地平面，不打断        │
│     │  L3: Power (电源层)          │ ← 3.3V / VBAT 区域         │
│     │  L4: Signal (信号层)         │ ← 底面走线 + 测试点         │
│     └──────────────────────────────┘                             │
│                                                                  │
│  ☑  关键走线规则:                                                │
│     - I²C (SDA/SCL): 等长走线，阻抗控制非必须 (100kHz)          │
│     - SPI (BNO085 RPT模式时): 走线 < 5cm，阻抗 50Ω              │
│     - ADC (VBAT_SENSE): 远离数字信号，加地保护环                 │
│     - 天线馈线: 50Ω 微带线，走 L1，参考 L2 地平面               │
│                                                                  │
│  ☑  去耦电容布局:                                                │
│     - 每个 IC VDD 引脚: 100nF (0402) 紧贴引脚放置               │
│     - 每个电源域: 10µF (0805) 集中放置                          │
│     - ESP32-S3: 每个 VDD 引脚独立 100nF                         │
│                                                                  │
│  ☑  Flex 传感器连接器:                                           │
│     - 使用 2.54mm 间距排针或 FPC 连接器                         │
│     - 安装在 PCB 边缘，便于线缆走线                              │
│                                                                  │
│  ☑  尺寸约束:                                                    │
│     - 手套 PCB: ≤ 30mm × 40mm                                   │
│     - 接收器 PCB: ≤ 25mm × 35mm                                 │
│     - 板厚: 1.0mm (减少重量)                                     │
│                                                                  │
│  ☑  重量目标: 单手套电子部分 < 25g (含电池)                      │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

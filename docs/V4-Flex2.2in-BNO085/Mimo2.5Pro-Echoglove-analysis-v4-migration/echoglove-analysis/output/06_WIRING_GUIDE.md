## 2 I2C 总线接线

### 2.1 总线拓扑

| 设备 | I2C 地址 | ADDR 引脚配置 | 说明 |
|------|----------|---------------|------|
| BNO085 | 0x4B | ADR→3.3V (默认) | 9-DOF IMU，Game Rotation Vector 模式 |
| ADS1115 #1 | 0x48 | ADDR→GND | 16-bit ADC，读 Flex 1-4 (Index/Middle/Ring/Pinky) |
| ADS1115 #2 | 0x49 | ADDR→VDD (3.3V) | 16-bit ADC，读 Flex 5 (Thumb) |

### 2.2 接线详情

```
ESP32-S3                    I2C Bus
─────────                   ───────
GPIO8 (SDA) ──────┬──────── 所有 SDA 引脚
                   │
                   ├── 4.7kΩ ──── 3.3V (上拉电阻)

GPIO9 (SCL) ──────┬──────── 所有 SCL 引脚
                   │
                   ├── 4.7kΩ ──── 3.3V (上拉电阻)

3.3V ──────────────────────── 所有 VCC 引脚
GND ───────────────────────── 所有 GND 引脚
```

**注意事项**：
- 上拉电阻 4.7kΩ 必须，通常 ADS1115 模块已内置，BNO085 模块也可能内置
- 如果总线不稳定，尝试降低频率至 100kHz
- I2C 线缆长度建议 < 30cm，过长会导致信号衰减
- SDA/SCL 走线应平行走线，间距 < 2mm

## 3 BNO085 接线

### 3.1 GY-BNO085 模块引脚

| BNO085 引脚 | ESP32-S3 引脚 | 说明 |
|-------------|---------------|------|
| VCC | 3.3V | **必须 3.3V，不可接 5V** |
| GND | GND | 共地 |
| SDA | GPIO8 | I2C 数据线 |
| SCL | GPIO9 | I2C 时钟线 |
| INT | GPIO21 | 中断输出（可选，上拉） |
| RST | NC | 复位引脚（悬空或接 3.3V） |
| ADR/PS0 | 3.3V | I2C 地址选择：3.3V→0x4B，GND→0x4A |

### 3.2 注意事项

- BNO085 工作电压 **严格 3.3V**，接 5V 会永久损坏
- 初始化时需要约 400ms 启动时间
- Game Rotation Vector 模式下不使用磁力计，yaw 会漂移 1-5°/min
- 模块应远离强磁场（已移除磁铁，此问题不再存在）

## 5 弯曲传感器接线

### 5.1 电压分压电路（每路相同）

```
3.3V ──── [Flex Sensor] ────┬─── ADS1115 AINx
                             │
                        [10kΩ Resistor]
                             │
                            GND
```

**电路原理**：
- 弯曲传感器与 10kΩ 下拉电阻串联，形成分压电路
- 平直时：传感器电阻 ~10kΩ → 分压 = 3.3V × 10k/(10k+10k) = **1.65V**
- 完全弯曲(90°)：传感器电阻 ~30-125kΩ → 分压 ≈ **2.94V** (以125kΩ计)
- 动态范围：1.65V → 2.94V ≈ **1.29V**

### 5.2 每路接线详情

| 手指 | ADS1115 模块 | 通道 | 接线方式 |
|------|-------------|------|----------|
| 食指 (Index) | #1 (0x48) | AIN0 | 3.3V→Flex→AIN0+10kΩ→GND |
| 中指 (Middle) | #1 (0x48) | AIN1 | 3.3V→Flex→AIN1+10kΩ→GND |
| 无名指 (Ring) | #1 (0x48) | AIN2 | 3.3V→Flex→AIN2+10kΩ→GND |
| 小指 (Pinky) | #1 (0x48) | AIN3 | 3.3V→Flex→AIN3+10kΩ→GND |
| 拇指 (Thumb) | #2 (0x49) | AIN0 | 3.3V→Flex→AIN0+10kΩ→GND |

### 5.3 滤波电容（推荐）

每个 ADC 输入通道并联一个 **100nF (0.1μF) 陶瓷电容** 到 GND，用于滤除高频噪声：

```
3.3V ── [Flex] ──┬── ADS1115 AINx
                  │
             [10kΩ]    [100nF]
                  │        │
                 GND      GND
```

### 5.4 弯曲传感器安装方向

```
          手指背面（指甲侧）
    ┌─────────────────────────┐
    │  ═══════════════════    │ ← 弯曲传感器（活性面朝外）
    │                         │
    │      指腹侧             │
    └─────────────────────────┘

    弯曲方向：手指弯曲时，传感器活性面被拉伸
    安装位置：覆盖 MCP 关节到 PIP 关节之间
    固定方式：双面胶或硅胶套固定，避免滑动
```

**关键**：传感器活性面（有碳膜的一面）必须朝向外侧（被拉伸侧），否则弯曲时电阻变化方向相反。

## 7 电源分配

### 7.1 供电需求

| 组件 | 典型电流 | 最大电流 | 供电电压 |
|------|----------|----------|----------|
| ESP32-S3 (WiFi 活跃) | 120mA | 350mA | 3.3V |
| BNO085 | 15mA | 25mA | 3.3V |
| ADS1115 × 2 | 0.3mA | 0.5mA | 3.3V |
| Flex Sensor × 5 (分压电流) | 0.16mA | 0.33mA | 3.3V |
| LED | 5mA | 20mA | 3.3V |
| **总计** | **~140mA** | **~400mA** | **3.3V** |

### 7.2 电源建议

- 使用 3.7V LiPo + LDO (AMS1117-3.3) 或直接用 USB 供电调试
- 建议在 3.3V 供电入口并联 **100μF 电解电容 + 100nF 陶瓷电容** 去耦
- ESP32-S3 模块自带 LDO，可从 VIN(5V) 供电，内部转 3.3V
- 电池建议 600mAh 以上，续航 > 8 小时

## 8 常见接线错误与调试

### 8.1 I2C 扫描工具

如果设备无法识别，先用 I2C 扫描确认地址：

```cpp
// 在 ESP32 上运行 I2C 扫描
#include <Wire.h>
void setup() {
  Serial.begin(115200);
  Wire.begin(8, 9); // SDA=8, SCL=9
  for (byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {
      Serial.printf("Found device at 0x%02X\n", addr);
    }
  }
}
```

预期发现：0x48, 0x49, 0x4B（或 0x4A）

### 8.2 常见问题排查

| 症状 | 可能原因 | 解决方案 |
|------|----------|----------|
| I2C 扫描无设备 | SDA/SCL 接反 | 检查 GPIO8→SDA, GPIO9→SCL |
| 只找到一个 ADS1115 | ADDR 引脚配置错误 | 确认 #1 接 GND, #2 接 VDD |
| ADS1115 读数全为 0 | Flex 传感器未接或断裂 | 用万用表测分压点电压 |
| ADS1115 读数全为 32767 | 分压电阻开路 | 检查 10kΩ 下拉电阻焊接 |
| BNO085 读数不稳定 | 供电不足或 I2C 干扰 | 加去耦电容，降低 I2C 频率 |
| 弯曲方向反了 | 传感器活性面装反 | 翻转传感器或在软件中取反 |
| 弯曲读数不线性 | 传感器贴合不紧 | 重新固定，确保贴合指面 |
| I2C 偶发 NACK | 总线竞争或线缆过长 | 加 100Ω 串阻，缩短线缆 |

### 8.3 万用表快速验证

1. **供电验证**：量 3.3V 轨是否稳定（±5% = 3.14-3.47V）
2. **I2C 验证**：SDA/SCL 空闲时应为高电平（~3.3V）
3. **Flex 验证**：量 AIN0-AIN3 对 GND 电压，弯曲手指时应有 1.65V→2.9V 变化
4. **BNO085 验证**：量 INT 引脚应有周期性脉冲（100Hz）

## 9 PCB 布局建议（如果自制 PCB）

1. **模拟区域与数字区域分离**：ADS1115 及分压电路放在模拟区，远离 ESP32 天线
2. **I2C 走线**：SDA/SCL 平行走线，长度 < 10cm，远离高速信号线
3. **去耦电容**：每个 IC 的 VCC/GND 间放 100nF，靠近引脚
4. **Flex 连接器**：使用 FPC 或 JST 连接器，便于更换传感器
5. **地平面**：完整地平面，模拟地和数字地单点连接

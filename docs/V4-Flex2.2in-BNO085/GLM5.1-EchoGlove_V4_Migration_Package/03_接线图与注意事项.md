## 2. 弯曲传感器接线详图

```
    每个弯曲传感器的电压分压电路：

    3.3V
     │
     ├── Flex Sensor (10kΩ~125kΩ)
     │        │
     │        ├──────→ ADS1115 A0/A1/A2/A3
     │        │
     ├── 10kΩ 下拉电阻
     │        │
    GND      GND

    输出电压计算：
    Vout = 3.3V × R_pulldown / (R_flex + R_pulldown)

    手指伸直时: R_flex ≈ 10kΩ → Vout = 3.3 × 10/(10+10) = 1.65V
    手指弯曲时: R_flex ≈ 125kΩ → Vout = 3.3 × 10/(125+10) = 0.244V

    注意：Spectra Symbol 2.2" 传感器的阻值随弯曲增大
    （平直约10kΩ，完全弯曲约60-125kΩ）
```

## 6. 关键注意事项

### 6.1 ADS1115 配置要点

1. **两片ADS1115的ADDR引脚必须不同接法**：
   - ADS1115 #1: ADDR → GND → I2C地址 0x48
   - ADS1115 #2: ADDR → VDD → I2C地址 0x49
   - **如果两片都接GND，地址冲突0x48，无法通信！**

2. **PGA增益设置**：
   - 推荐设为 ±2.048V (GAIN_FOUR = 4x)
   - Flex分压输出范围 ~0.244V-1.65V
   - ±2.048V量程下分辨率 = 2.048/32768 = 0.0625mV
   - 绝对够用，无需更高增益

3. **采样率设置**：
   - 设为 860 SPS (最高)
   - 5通道轮询：每通道 ~172 SPS
   - 远超100Hz需求，有充足余量

4. **未使用通道处理**：
   - ADS1115 #2的 A1/A2/A3 必须接GND
   - 避免浮空输入产生噪声耦合

### 6.2 弯曲传感器安装要点

1. **传感器方向**：
   - Flex传感器有方向性！平的一面朝手背
   - 弯曲时电阻增大方向正确
   - 反装会导致弯曲时电阻减小，逻辑反转

2. **固定方式**：
   - 用医用胶带或缝入手套内侧
   - 传感器中心对准MCP关节（掌指关节）
   - 2.2"传感器覆盖范围：MCP→PIP关节区域
   - 确保传感器可以自由弯曲，不被过度拉伸

3. **校准位置**：
   - 伸直状态：五指完全伸直张开
   - 弯曲状态：握拳，各指尽量弯曲
   - 每次佩戴后建议重新校准（2秒流程）

4. **线缆管理**：
   - 传感器引出线沿手指背部走线
   - 用热缩管或硅胶线减少弯折疲劳
   - 汇合点在手腕处，避免影响手部运动

### 6.3 BNO085 配置要点

1. **I2C地址确认**：
   - 7Semi GY-BNO085 (SDO→GND) → 0x4B
   - 文档可能写0x4A，实际为0x4B
   - 建议运行时探测两个地址确认

2. **必须使用 Game Rotation Vector 模式**：
   - SH2_GAME_ROTATION_VECTOR (6轴融合)
   - 不使用磁力计，免受磁场干扰
   - 不要用 ROTATION_VECTOR (9轴)
   - 输出：四元数(w,x,y,z) + 角速度(x,y,z)

3. **去耦电容**：
   - 0.1µF 陶瓷电容 + 10µF 电解电容
   - 尽量靠近BNO085模块的VCC/GND引脚

4. **INT中断**：
   - GPIO21，active-low
   - 100Hz数据就绪中断
   - 内部上拉(PULLUP)

### 6.4 I2C总线注意事项

1. **上拉电阻**：
   - SDA/SCL各接一个4.7kΩ上拉电阻到3.3V
   - 部分模块内置上拉，需确认不重复
   - 总线上拉电阻并联值应在2kΩ-10kΩ范围

2. **总线负载**：
   - 3个设备(2×ADS1115 + 1×BNO085)在400kHz下运行
   - 总线电容 < 400pF（标准模式）
   - 线缆长度建议 < 30cm

3. **通信时序**：
   - ADS1115单次转换时间：~1.16ms @860SPS
   - 5通道轮询：~6ms
   - BNO085读取：~1ms
   - 总采样周期：~7ms → 支持>100Hz

4. **调试技巧**：
   - 先用 I2C Scanner 确认3个设备地址
   - 分别读取ADS1115的设备ID寄存器确认通信
   - 用串口打印原始ADC值验证

### 6.5 常见陷阱与避坑指南

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| ADS1115两片地址相同 | I2C通信失败 | 确保一片ADDR=GND(0x48), 另一片ADDR=VDD(0x49) |
| Flex传感器方向反了 | 弯曲时信号反转 | 安装前用万用表测试：弯曲时阻值应增大 |
| 下拉电阻忘记焊 | ADC读数为浮空噪声 | 必须焊接10kΩ下拉电阻 |
| BNO085用ROTATION_VECTOR | 磁力计可能误校准 | 坚持用GAME_ROTATION_VECTOR |
| 未使用的ADC通道浮空 | 噪声耦合到其他通道 | ADS1115 #2的A1/A2/A3接GND |
| I2C上拉电阻重复 | 并联值过小，信号失真 | 检查模块是否内置上拉 |
| Flex传感器过度弯折 | 传感器损伤 | 弯曲角度不超过180° |

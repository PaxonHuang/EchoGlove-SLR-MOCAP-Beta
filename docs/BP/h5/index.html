摘要

EXEC SUMMARY

具身智能(Physical AI)的最大瓶颈不是移动，而是 Manipulation(操作)。 操作学习需要大量人类示教数据，而现有采集手段(UMI/ALOHA)成本高、缺人体本体感觉与触觉。 EchoGlove 以可穿戴形态填补"低成本人体手部意图捕捉"空白，定位为 Human Hand Intelligence Layer —— 介于机器人本体/基础模型与应用之间的数据入口层。

纯 CV 物理天花板

接触力=0(全域空白)、遮挡脆弱、无绝对 6DoF 世界位姿、光照依赖、本体状态缺失。测量模态差距，非参数优化差距，无法被 CV 算法迭代弥补。

空白 ④
数据平台蓝海

所有竞品"卖硬件+SDK"，无一家把"采集→标注→数据集→模型评估"作产品闭环。OpenX/DROID 主流数据集根本无力/触觉字段。

空白 ⑤
多场景 + 国产化

无一产品同时覆盖手势识别+康复+VR/MR+机器人遥操+数据采集。Noitom 虽国产但闭源/价格不透明/无数据平台。

一句话定位 · ONE-LINER

EchoGlove 是具身智能时代的 "Human Data Capture Layer" —— 以百美元级可穿戴手套，补齐当前 UMI/ALOHA/DexCap 生态缺失的 "人手侧本体感觉 + 力/触觉"数据流， 为 π0/OpenVLA/RT-2 等 VLA 基础模型提供规模化、低成本、力控密集的高质量人类演示数据。

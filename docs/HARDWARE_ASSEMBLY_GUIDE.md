## 2 I²C 总线接线

### 2.1 V5 扁平总线拓扑（无 MUX）

```
┌──────────────────────────────────────────────────────────┐
│              ESP32-S3  I²C Bus (100kHz)                   │
│                                                           │
│   GPIO8 (SDA) ──┬──────────┬──────────┬── 3.3V (2.2kΩ)   │
│   GPIO9 (SCL) ──┼──────────┼──────────┼── 3.3V (2.2kΩ)   │
│                 │          │          │                    │
│            ┌────┴────┐ ┌───┴───┐ ┌────┴────┐             │
│            │ADS1115  │ │ADS1115│ │ BNO085  │             │
│            │ #1      │ │ #2    │ │         │             │
│            │ 0x48    │ │ 0x49  │ │ 0x4B    │             │
│            └────┬────┘ └───┬───┘ └─────────┘             │
│             Flex0-2     Flex3-4                            │
└──────────────────────────────────────────────────────────┘
```

**V5 优势**: 无 MUX 地址冲突风险，总线更简单可靠。

### 2.2 上拉电阻选择

| 总线       | 电阻值         | 说明                             |
| ---------- | -------------- | -------------------------------- |
| 主 SDA/SCL | 2.2kΩ → 3.3V | 100kHz 标准，覆盖 3 个设备       |
| Flex ADC   | 47kΩ → GND   | 分压下拉，与柔性传感器形成分压器 |

## 3 逐传感器接线详表

### 3.1 BNO085 IMU (0x4B)

| BNO085 引脚 | ESP32-S3 引脚 | 说明          |
| ----------- | ------------- | ------------- |
| VCC         | 3.3V          | 供电          |
| GND         | GND           | 地            |
| SDA         | GPIO8         | I²C 数据     |
| SCL         | GPIO9         | I²C 时钟     |
| INT         | GPIO1         | 中断（可选）  |
| RST         | —            | 悬空或接 3.3V |

### 3.2 ADS1115 #1 (0x48) — Flex 0-2

| ADS1115 引脚 | ESP32-S3 引脚 | 说明      |
| ------------ | ------------- | --------- |
| VCC          | 3.3V          | 供电      |
| GND          | GND           | 地        |
| SDA          | GPIO8         | I²C 数据 |
| SCL          | GPIO9         | I²C 时钟 |
| ADDR         | GND           | 地址 0x48 |
| A0           | Flex 0 (拇指) | ADC 输入  |
| A1           | Flex 1 (食指) | ADC 输入  |
| A2           | Flex 2 (中指) | ADC 输入  |
| A3           | —            | 未使用    |

### 3.3 ADS1115 #2 (0x49) — Flex 3-4

| ADS1115 引脚 | ESP32-S3 引脚   | 说明      |
| ------------ | --------------- | --------- |
| VCC          | 3.3V            | 供电      |
| GND          | GND             | 地        |
| SDA          | GPIO8           | I²C 数据 |
| SCL          | GPIO9           | I²C 时钟 |
| ADDR         | 3.3V            | 地址 0x49 |
| A0           | Flex 3 (无名指) | ADC 输入  |
| A1           | Flex 4 (小指)   | ADC 输入  |
| A2           | —              | 未使用    |
| A3           | —              | 未使用    |

### 3.4 柔性传感器分压电路

每个柔性传感器与 47kΩ 下拉电阻构成分压器：

```
3.3V ─── [Flex Sensor] ──┬── [47kΩ] ─── GND
                          │
                          └── ADS1115 AINx
```

- 弯曲时电阻增大 → AIN 电压升高
- 校准范围: ~0.3V（伸直）→ ~2.8V（完全弯曲）

## 6 手套物理安装布局

### 6.1 传感器位置

```
        手背（上方）
    ┌───────────────────┐
    │    ESP32-S3       │ ← 手背中央
    │    BNO085         │ ← 手背中央（ESP32 旁）
    │    ADS1115 ×2     │ ← 手背两侧
    └───────────────────┘
         │ │ │ │ │
         │ │ │ │ └── Flex 4 (小指 MCP)
         │ │ │ └──── Flex 3 (无名指 MCP)
         │ │ └────── Flex 2 (中指 MCP)
         │ └──────── Flex 1 (食指 MCP)
         └────────── Flex 0 (拇指 MCP)
```

### 6.2 安装要点

1. **BNO085**: 安装在手背中央，远离磁性材料
2. **柔性传感器**: 沿手指背面放置，MCP 关节处弯曲
3. **走线**: 沿手背走线，用热熔胶固定
4. **电池**: 手腕处口袋固定

## 7 焊接顺序与注意事项

### 7.1 推荐焊接顺序

1. **I²C 上拉电阻** (2.2kΩ) → GPIO8/9 → 3.3V
2. **ADS1115 模块** → I²C + ADDR 配置
3. **BNO085 模块** → I²C + INT
4. **分压电阻** (47kΩ) → ADS1115 ADC 输入
5. **柔性传感器** → 分压电路
6. **WS2812B LED** → GPIO2
7. **校准按键** → GPIO1
8. **电池管理** → TP4056 + AMS1117

### 7.2 注意事项

- **无 MUX**: V5 不需要 TCA9548A，直接扁平总线
- **ADDR 引脚**: ADS1115 #1 接 GND (0x48)，#2 接 3.3V (0x49)
- **BNO085 地址**: 确认 0x4B（不是 0x4A）
- **ESD 防护**: 处理 BNO085 时注意静电防护

## 8 上电验证流程

### 8.1 逐步验证

```bash
# 1. 仅接 ESP32-S3，不接传感器
# 确认 USB 串口可用
ls /dev/ttyUSB*  # 或 /dev/ttyACM*

# 2. I²C 扫描（应发现 3 个设备）
pio device monitor -b 115200
# 预期输出:
# I2C scan: 0x48 (ADS1115 #1)
# I2C scan: 0x49 (ADS1115 #2)
# I2C scan: 0x4B (BNO085)

# 3. 传感器数据测试
# 预期: flex[5] + euler[3] + gyro[3] @ 100Hz

# 4. ESP-NOW 测试
# 左手套 → 接收器，确认 69-byte GlovePacket
```

### 8.2 预期 I²C 设备

| 地址 | 设备       | 验证方法             |
| ---- | ---------- | -------------------- |
| 0x48 | ADS1115 #1 | 读取 A0-A2 ADC 值    |
| 0x49 | ADS1115 #2 | 读取 A0-A1 ADC 值    |
| 0x4B | BNO085     | 读取 Euler/Gyro 数据 |

## 9 常见故障排查

### 9.1 I²C 扫描找不到设备

| 现象     | 可能原因              | 解决方法                    |
| -------- | --------------------- | --------------------------- |
| 无设备   | SDA/SCL 接反          | 检查 GPIO8→SDA, GPIO9→SCL |
| 无设备   | 上拉电阻缺失          | 安装 2.2kΩ 上拉到 3.3V     |
| 仅 0x4B  | ADS1115 ADDR 未接     | 检查 ADDR 引脚配置          |
| 地址冲突 | 两个 ADS1115 地址相同 | #1 ADDR→GND, #2 ADDR→3.3V |

### 9.2 柔性传感器读数异常

| 现象       | 可能原因     | 解决方法            |
| ---------- | ------------ | ------------------- |
| 始终 0     | 分压电阻未接 | 安装 47kΩ 下拉电阻 |
| 始终满量程 | 传感器断路   | 检查焊接点          |
| 噪声大     | 走线过长     | 缩短传感器引线      |

### 9.3 BNO085 数据异常

| 现象       | 可能原因     | 解决方法       |
| ---------- | ------------ | -------------- |
| Euler 全 0 | IMU 未初始化 | 检查 I²C 通信 |
| 数据漂移   | 磁干扰       | 远离磁铁/电机  |
| 不更新     | INT 引脚未接 | 连接 GPIO1     |

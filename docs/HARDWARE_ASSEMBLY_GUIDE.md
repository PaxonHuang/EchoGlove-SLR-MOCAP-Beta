## 2 I²C 总线接线

### 2.1 V5 扁平总线拓扑（无 MUX）

```
┌──────────────────────────────────────────────────────────┐
│              ESP32-S3  I²C Bus (100kHz)                   │
│                                                           │
│   GPIO8 (SDA) ──┬──────────┬──────────┬── 3.3V (4.7kΩ)   │
│   GPIO9 (SCL) ──┼──────────┼──────────┼── 3.3V (4.7kΩ)   │
│                 │          │          │                    │
│            ┌────┴────┐ ┌───┴───┐ ┌────┴────┐             │
│            │ADS1115  │ │ADS1115│ │ BNO085  │             │
│            │ #1      │ │ #2    │ │         │             │
│            │ 0x48    │ │ 0x49  │ │ 0x4B    │             │
│            └────┬────┘ └───┬───┘ └─────────┘             │
│             Flex0-2     Flex3-4                            │
└──────────────────────────────────────────────────────────┘
```

**V5 优势**: 无 MUX 地址冲突风险，总线更简单可靠。

### 2.2 上拉电阻选择

| 总线       | 电阻值           | 说明                             |
| ---------- | ---------------- | -------------------------------- |
| 主 SDA/SCL | **4.7kΩ → 3.3V** | I²C 标准模式推荐值，覆盖 3 设备  |
| Flex 分压  | **47kΩ → 3.3V**  | 分压上拉，与柔性传感器形成分压器 |

> **⚠️ 4.7kΩ vs 47kΩ 区别**：
> - **4.7kΩ** (4千7百欧) = I²C 上拉电阻，每个 I²C 总线 2 个（SDA + SCL）
> - **47kΩ** (4万7千欧) = 柔性传感器分压电阻，每个传感器 1 个，共 5 个
> - 两者相差 10 倍，用途完全不同，**不可混用**

### 2.3 I²C 上拉电阻计算依据

- I²C 标准模式 (100kHz)：上升时间 t_r ≤ 1000ns
- 公式：R_pull ≤ t_r / (0.8473 × C_bus)
- 总线电容估算：3 个 IC (约 60pF) + 面包板跳线 (约 80pF) ≈ 140pF
- R_pull ≤ 1000ns / (0.8473 × 140pF) ≈ 8.4kΩ
- **4.7kΩ** 提供充足裕量，同时不会过强（空闲电流仅 0.7mA/线）

## 3 逐传感器接线详表

### 3.1 BNO085 IMU (0x4B)

| BNO085 引脚 | ESP32-S3 引脚 | 说明          |
| ----------- | ------------- | ------------- |
| VCC         | 3.3V          | 供电          |
| GND         | GND           | 地            |
| SDA         | GPIO8         | I²C 数据     |
| SCL         | GPIO9         | I²C 时钟     |
| INT         | GPIO1         | 中断（可选）  |
| RST         | **3.3V**     | **必须拉高**，否则 I²C 不响应 |

> **⚠️ RST 引脚关键**：BNO085 的 RST 引脚必须接到 3.3V（拉高），否则芯片处于复位状态，I²C 不会响应。悬空 = 不工作。

### 3.4 柔性传感器分压电路

每个柔性传感器与 47kΩ 上拉电阻构成分压器：

```
3.3V ── [47kΩ] ──┬── [Flex Sensor] ── GND
                  │
                  └── ADS1115 AINx
```

> **⚠️ 重要：47kΩ 接 3.3V 侧，传感器接 GND 侧**
>
> 这样连接时：
> - **伸直**：传感器电阻低 (~22kΩ) → AIN 电压低 (~1.05V)
> - **弯曲**：传感器电阻高 (~110kΩ) → AIN 电压高 (~2.31V)
> - 电压范围：约 1.05V ~ 2.31V（1.26V 摆幅）
> - ADS1115 在 ±4.096V 增益下可正常读取

**电压计算**：
```
V_AIN = 3.3V × R_flex / (R_flex + 47kΩ)

伸直 (R_flex=22kΩ):  V = 3.3 × 22k/69k  = 1.05V
半弯 (R_flex=60kΩ):  V = 3.3 × 60k/107k = 1.86V
全弯 (R_flex=110kΩ): V = 3.3 × 110k/157k = 2.31V
```

## 6 手套物理安装布局

### 6.1 传感器位置

```
        手背（上方）
    ┌───────────────────┐
    │    ESP32-S3       │ ← 手背中央
    │    BNO085         │ ← 手背中央（ESP32 旁）
    │    ADS1115 ×2     │ ← 手背两侧
    └───────────────────┘
         │ │ │ │ │
         │ │ │ │ └── Flex 4 (小指 MCP)
         │ │ │ └──── Flex 3 (无名指 MCP)
         │ │ └────── Flex 2 (中指 MCP)
         │ └──────── Flex 1 (食指 MCP)
         └────────── Flex 0 (拇指 MCP)
```

### 6.2 安装要点

1. **BNO085**: 安装在手背中央，远离磁性材料
2. **柔性传感器**: 沿手指背面放置，MCP 关节处弯曲
3. **走线**: 沿手背走线，用热熔胶固定
4. **电池**: 手腕处口袋固定

## 7 焊接顺序与注意事项

### 7.1 推荐焊接顺序

1. **I²C 上拉电阻** (4.7kΩ) → GPIO8/9 → 3.3V
2. **ADS1115 模块** → I²C + ADDR 配置
3. **BNO085 模块** → I²C + RST(→3.3V) + PS0(→3.3V) + PS1(→GND)
4. **分压电阻** (47kΩ → 3.3V) → ADS1115 ADC 输入
5. **柔性传感器** → 分压电路（传感器侧接 GND）
6. **WS2812B LED** → GPIO2
7. **校准按键** → GPIO1
8. **电池管理** → TP4056 + AMS1117

### 7.2 注意事项

- **无 MUX**: V5 不需要 TCA9548A，直接扁平总线
- **ADDR 引脚**: ADS1115 #1 接 GND (0x48)，#2 接 3.3V (0x49)
- **BNO085 地址**: 确认 0x4B（不是 0x4A）
- **BNO085 RST**: 必须接 3.3V，不能悬空
- **ESD 防护**: 处理 BNO085 时注意静电防护
- **去耦电容**: 每个 IC 的 VDD 旁放 100nF 陶瓷电容

## 8 上电验证流程

### 8.1 逐步验证

```bash
# 1. 仅接 ESP32-S3，不接传感器
# 确认 USB 串口可用
ls /dev/ttyUSB*  # 或 /dev/ttyACM*

# 2. I²C 扫描（应发现 3 个设备）
pio device monitor -b 115200
# 预期输出:
# I2C scan: 0x48 (ADS1115 #1)
# I2C scan: 0x49 (ADS1115 #2)
# I2C scan: 0x4B (BNO085)

# 3. 传感器数据测试
# 预期: flex[5] + euler[3] + gyro[3] @ 100Hz

# 4. ESP-NOW 测试
# 左手套 → 接收器，确认 69-byte GlovePacket
```

### 8.2 预期 I²C 设备

| 地址 | 设备       | 验证方法             |
| ---- | ---------- | -------------------- |
| 0x48 | ADS1115 #1 | 读取 A0-A2 ADC 值    |
| 0x49 | ADS1115 #2 | 读取 A0-A1 ADC 值    |
| 0x4B | BNO085     | 读取 Euler/Gyro 数据 |

### 8.3 面包板接线检查清单

上电前务必用万用表检查：

| 检查项 | 方法 | 预期 |
|--------|------|------|
| I²C 上拉 | 电阻档：GPIO8↔3.3V | 4.7kΩ |
| I²C 上拉 | 电阻档：GPIO9↔3.3V | 4.7kΩ |
| SDA↔SCL | 电阻档 | >100kΩ（不短路） |
| SDA↔GND | 电阻档 | >100kΩ（不短路） |
| BNO085 RST | 通断档：RST↔3.3V | 通路 |

## 9 常见故障排查

### 9.1 I²C 扫描找不到设备

| 现象     | 可能原因                | 解决方法                         |
| -------- | ----------------------- | -------------------------------- |
| 无设备   | SDA/SCL 接反            | 检查 GPIO8→SDA, GPIO9→SCL      |
| 无设备   | 上拉电阻缺失            | 安装 4.7kΩ 上拉到 3.3V          |
| 无设备   | BNO085 RST 悬空         | RST 必须接 3.3V                  |
| 无设备   | 面包板接触不良          | 重新插拔跳线，确认接触牢固       |
| 仅 0x4B  | ADS1115 ADDR 未接       | 检查 ADDR 引脚配置               |
| 地址冲突 | 两个 ADS1115 地址相同   | #1 ADDR→GND, #2 ADDR→3.3V      |
| 扫描卡死 | I²C 总线被设备锁死      | 断电重启，检查 SDA/SCL 是否被拉低 |

### 9.2 I²C 读取失败（err=5 / err=263）

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| `i2cRead returned Error 263` | 设备不发 ACK | 检查 VCC/GND 供电 |
| `endTransmission() err=5` | I²C 超时 | 检查 SDA/SCL 连接 |
| `endTransmission() err=2` | 地址无响应 | 确认设备地址正确 |
| 读取值全为 0 | ADS1115 未初始化 | 检查 I²C 通信 |
| 读取值为垃圾数 | 总线数据错误 | 检查上拉电阻、走线长度 |

### 9.3 柔性传感器读数异常

| 现象       | 可能原因           | 解决方法                   |
| ---------- | ------------------ | -------------------------- |
| 始终 0     | 分压电阻未接       | 安装 47kΩ 上拉到 3.3V     |
| 始终满量程 | 传感器断路         | 检查焊接点                 |
| 噪声大     | 走线过长           | 缩短传感器引线             |
| 弯曲时电压降低 | 传感器/电阻位置接反 | 47kΩ 接 3.3V，传感器接 GND |

### 9.4 BNO085 数据异常

| 现象       | 可能原因     | 解决方法              |
| ---------- | ------------ | --------------------- |
| I²C 不响应 | RST 悬空     | RST 接 3.3V           |
| Euler 全 0 | IMU 未初始化 | 检查 I²C 通信         |
| 数据漂移   | 磁干扰       | 远离磁铁/电机         |
| 不更新     | INT 引脚未接 | 连接 GPIO1            |
